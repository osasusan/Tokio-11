
# Localización en iOS

Proyecto de práctica para aprender a localizar aplicaciones iOS 
en múltiples idiomas usando Swift y UIKit.

### Contenido
- Localización de elementos desde el Storyboard con archivos .strings
- Localización de textos desde código con NSLocalizedString
- Soporte para español e inglés

### Tecnologías
- Swift
- UIKit
- Xcode Localization System
